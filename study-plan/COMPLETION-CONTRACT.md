# Curriculum Completion Contract

Every child-topic directory is complete only when it contains a standalone `lesson.md` intended for 2–4 hours of study with all of the following sections:

1. Foundations — first principles, motivation/history, contextual terminology.
2. Core Mechanics — every major rule/subcase, worked data/code, boundaries.
3. Worked Problems — at least eight, easy through hard, each with reasoning and mistake caught.
4. Real-World / Applied Context — two or three named systems with concrete data/code/measurements.
5. Comparison Table — specific trade-offs and costs.
6. Common Mistakes & Misconceptions — concrete incorrect and corrected reasoning.
7. Cheat Sheet — explicitly marked review-only.
8. Practice Set — six to ten new unsolved questions.
9. Curated Resources — exact primary source and value added.
10. Related Topics Bridge — explicit prerequisites and successors.
11. `---ANSWER KEY BELOW---` — final section, after all self-test questions.

Additional requirements:

- No placeholder metrics or inputs.
- Code must be syntactically valid and, where practical, compiled/tested.
- Version-sensitive technical claims must name the version and primary documentation.
- Measured numbers must name environment/method and must not be generalized as universal.
- Security, privacy, cost and failure boundaries must appear wherever relevant.
