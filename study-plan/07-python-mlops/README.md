# Parent 07 — Python and MLOps

This parent builds from reliable Python services through ML evaluation, lifecycle,
serving and LLM-specific platform controls.

No Python, mathematics/statistics, ML, or generative-AI knowledge is assumed.

## Phase A — Python prerequisites

1. [Python Language Fundamentals](06-python-language-fundamentals/lesson.md) — edit/run loop, values, names, types, expressions, control flow, functions, modules, exceptions, files and debugging.
2. [Python Collections, Functions, and Object-Oriented Programming](07-python-collections-functions-oop/lesson.md) — containers, iteration, comprehensions, call semantics, classes, dataclasses, protocols, composition and resource management.
3. [Python Tooling, Testing, Packaging, and Data Handling](08-python-tooling-testing-data/lesson.md) — environments, dependencies, project layout, typing, pytest, logging, JSON/CSV, NumPy/pandas and reproducibility.

## Phase B — Mathematics and AI prerequisites

4. [Mathematics and Statistics for ML](09-math-statistics-for-ml/lesson.md) — algebra, vectors/matrices, calculus intuition, probability, distributions, estimation, hypothesis tests, metrics and experimental reasoning.
5. [Generative AI, Transformers, Embeddings, and RAG Foundations](10-generative-ai-llm-rag-foundations/lesson.md) — tokens, language modeling, attention, transformers, embeddings, prompting, retrieval, evaluation, safety and cost.

## Phase C — Existing advanced sequence

6. [Production Python](01-production-python/lesson.md) — complete; includes object/runtime/typing/concurrency/packaging/security mechanics and six passing source-layout package tests on CPython 3.13.4.
7. [FastAPI and Async](02-fastapi-async/lesson.md) — complete; includes ASGI/Pydantic v2, dependencies/lifespan, auth, deadline/backpressure and five passing tests on FastAPI 0.138.2.
8. [ML Fundamentals](03-ml-fundamentals/lesson.md) — complete; includes leakage-safe evaluation, core models, threshold/calibration/fairness, and five passing metric tests over a dated claims dataset.
9. [ML Lifecycle](04-ml-lifecycle/lesson.md) — complete; includes reproducibility, lineage, point-in-time features, pipelines, registry/promotion/monitoring controls and six passing adversarial manifest tests.
10. [Model Serving and LLMOps](05-model-serving-llmops/lesson.md) — complete; includes contracts, capacity/batching/autoscaling, GPU/LLM memory, RAG/evaluation/security and seven passing gateway-policy tests.

After all ten lessons, complete the [Python and MLOps Capstone](CAPSTONE.md), including its mandatory leakage, overload, RAG authorization, canary and delayed-label experiments.
